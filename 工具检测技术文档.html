一、检测方法总览

所有检测均通过 terminal 工具在 Git Bash (MSYS2) 环境中执行。核心原理：调用各工具的 --version 标志，根据退出码（exit code）和标准输出（stdout）判断安装状态。

二、逐工具详细解析

1. Node.js

$ node --version
v22.23.1
原理：Node.js 安装后会在系统 PATH 中注册 node.exe。--version 是 Node 内置的标准标志，输出当前 V8 引擎版本号。exit code 为 0 即表示可执行文件存在且能正常响应。

2. npm

$ npm --version
10.9.8
原理：npm 随 Node.js 一起安装（node 22.x 捆绑 npm 10.x）。npm --version 同样依赖 PATH 中的 npm 可执行文件。npm 实际是一个 Node.js 脚本，由 node.exe 解释执行。

3. Codex CLI

$ codex --version
codex-cli 0.142.2
原理：Codex CLI（OpenAI 出品）通过 npm 全局安装：npm install -g @openai/codex。安装后在 npm 全局 bin 目录下创建 codex 可执行文件，该目录已加入 PATH。检测时用 codex --version 直接输出版本。

4. Claude CLI

$ claude --version
bash: claude: command not found
原理：Shell 在 PATH 的所有目录中搜索名为 claude 的可执行文件，未找到则返回 "command not found"，exit code 127。这明确表示 Claude CLI 未安装。补充检测 claude-code 别名同样不存在。

5. Aider

$ aider --version
bash: aider: command not found
原理：Aider 是 Python 包，通常通过 pip install aider-chat 或 uv tool install aider-chat 安装。检测时在 PATH 中搜索 aider 可执行文件。未找到则判定未安装。pip list 中也不存在 aider 相关包。

6. Shell (Bash)

$ bash --version | head -1
GNU bash, version 5.3.9(1)-release (x86_64-pc-cygwin)
原理：bash 是当前会话的 Shell 解释器。本机安装的是 Git for Windows 自带的 MSYS2 Bash (Cygwin 编译版)。--version 输出 GNU Bash 的完整版本信息。

7. Python

$ python --version
Python 3.11.15
原理：Python 安装后在 PATH 中注册 python.exe。--version 直接输出版本。注意本机仅安装了 python（非 python3 别名），python3 命令不可用。pip 不可用，但 uv（Rust 写的 Python 包管理器）已安装，可作为替代。

四、通用检测逻辑

所有工具的检测遵循同一套流程：

  1. 构造命令：<tool> --version 2>&1（将 stderr 重定向到 stdout 一并捕获）
  2. 执行命令：在 Bash 子进程中运行，设置超时（10~15 秒）防止挂起
  3. 检查结果：
    • exit_code = 0 且 stdout 不含 "not found" → 已安装，提取版本号
    • exit_code ≠ 0 或 stdout 含 "command not found" → 未安装
    • 超时 → 可能存在但响应异常，标记为"不确定"
  4. 补充验证（可选）：对疑似未安装的工具，用 which、npx 或包管理器列表做二次确认

五、注意事项

  • PATH 环境变量是检测的关键——工具必须在其安装目录被加入 PATH 后才能被检测到。
  • 本机使用 Git Bash (MSYS2)，其 PATH 继承 Windows 系统 PATH 并追加 MSYS2 自身路径，因此同时能检测到 Windows 原生程序（如 python.exe）和 MSYS2 程序（如 bash）。
  • 部分工具可能安装在用户目录下（如 ~/bin/、~/AppData/Local/...），若未加入 PATH 则检测不到，需手动指定完整路径。
  • pip 不可用但 uv 可用——如需安装 Python 包（如 Aider），应使用 uv tool install 或 uv pip install。
